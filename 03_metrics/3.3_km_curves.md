# Kaplan-Meier Curves

The Kaplan–Meier (KM) estimator is the standard **non-parametric** way to estimate
the survival function $S(t)$ for a cohort or group, with no covariates and no
assumed curve shape. It is a useful descriptive reference, not a personalized prediction
model. Like the other standard methods here, it relies on independent censoring
(see [1.2 Censored Data](../01_background/1.2_censored_data.md#the-assumption-behind-standard-methods)).

## Estimator

KM walks through the event times and multiplies together the fraction surviving each one:

$$
\hat{S}(t) \;=\; \prod_{t_i \le t}\Big(1 - \underbrace{\frac{d_i}{n_i}}_{\text{fraction who fail at } t_i}\Big)
$$

where, at each distinct event time $t_i$:

- **$d_i$** is the number of **events** (e.g. deaths) at $t_i$.
- **$n_i$** is the number **at risk** *just before* $t_i$: everyone who has neither had the event nor been censored yet (the risk set from [2.1 Cox Proportional Hazards Loss](../02_loss_functions/2.1_cox_ph_loss.md#partial-likelihood)).

Each factor $(1 - d_i/n_i)$ is the conditional probability of remaining event-free
through $t_i$ given survival up to it; the running product produces the estimated
survival curve, a **step function** that drops at events and stays flat between them.

> **Worked example: five patients.** Times (★ = event, ○ = censored): 3★, 5★, 7○, 8★, 10○.
>
> | Event time $t_i$ | At risk $n_i$ | Events $d_i$ | Factor $1 - d_i/n_i$ | $\hat{S}(t)$ |
> |---|---|---|---|---|
> | 3 | 5 | 1 | $4/5 = 0.80$ | 0.80 |
> | 5 | 4 | 1 | $3/4 = 0.75$ | $0.80 \times 0.75 = 0.60$ |
> | 8 | 2 | 1 | $1/2 = 0.50$ | $0.60 \times 0.50 = 0.30$ |
>
> The censored patient at $t = 7$ produces **no drop**, but it lowers the at-risk count $n_i$ from 3 to 2 by the time of the event at $t = 8$, which is how censoring still informs the curve. The patient censored at 10 ends the followed range.

## In model evaluation

KM curves are used to:

1. **Visualize risk-group separation**: plot KM for high- vs. low-risk groups defined by the model's threshold (the figure below).
2. **Check group-level agreement**: compare the cohort-average predicted survival with the observed KM curve. This is a coarse check; horizon-specific calibration curves are more informative.
3. **Communicate results**: a familiar clinical summary when confidence bands and numbers at risk are included.

## Log-rank test

When comparing two KM curves (e.g. high- vs. low-risk groups), the **log-rank test** assesses whether the separation is statistically significant by comparing observed vs. expected events at each time point.

```python
from lifelines.statistics import logrank_test
result = logrank_test(T_high, T_low,
                      event_observed_A=E_high,
                      event_observed_B=E_low)
print(result.p_value)
```

## Choosing a risk threshold

A survival model outputs a *continuous* risk score; to draw the stratified KM plot below you must first **cut** that score into high- and low-risk groups at some threshold $\tau$. Three common ways to choose $\tau$, in increasing order of how much they lean on the outcome:

| Method | Rule | Pros / cons |
|---|---|---|
| **Median** | $\tau = \text{median}(r)$ | Simplest; always a 50/50 split; needs no outcome labels. But the true cutpoint may not sit at the median, and it can mislead on skewed scores. |
| **Youden index** | $\tau = \arg\max_\tau\,[\text{sens}(\tau) + \text{spec}(\tau) - 1]$ at a fixed time horizon | Grounded in diagnostic accuracy; balances false positives against false negatives. But requires choosing a horizon and binarizing the outcome. |
| **Max log-rank** | $\tau = \arg\max_\tau\,(\text{log-rank statistic between the two groups})$ | Directly maximizes KM separation; needs no horizon. But scanning many cutpoints inflates significance; see the warning. |

**Development→test discipline (all three methods).** Fit $\tau$ using only
development data, freeze the entire procedure, then apply it once to the test set.
If the model itself was fit on the training set, prefer a separate validation set or
nested cross-validation for outcome-guided cutpoint selection. A median training
cutpoint does not use outcomes and is a simpler baseline.

None of the three ships as a ready-made function. `scikit-survival`
(see [5.4 scikit-survival](../05_packages/5.4_scikit_survival.md)) provides the IPCW machinery and
`lifelines` (see [5.2 lifelines](../05_packages/5.2_lifelines.md)) the log-rank test, but you
assemble the cutpoint yourself:

```python
import numpy as np
from sksurv.util import Surv
from sksurv.metrics import CensoringDistributionEstimator
from sklearn.metrics import roc_curve
from lifelines.statistics import logrank_test

ev = E_train.astype(bool)                        # event indicator as boolean
y_train = Surv.from_arrays(event=ev, time=T_train)

# 1. Median: needs no outcome labels.
tau_median = np.median(risk_scores_train)

# 2. Youden at horizon t: build the IPCW-weighted cumulative/dynamic ROC,
#    then take the threshold maximising sens + spec - 1.
t = 24.0                                         # the horizon you will report
cde    = CensoringDistributionEstimator().fit(y_train)
w_case = cde.predict_ipcw(y_train)               # delta_i / G(T_i); 0 if censored
G_t    = cde.predict_proba(np.array([t]))[0]     # G(t), the shared control weight
is_case = ev & (T_train <= t)                    # had the event by t
is_ctrl = T_train > t                            # known to be event-free at t
w = np.where(is_case, w_case, 0.0) + np.where(is_ctrl, 1.0 / G_t, 0.0)
keep = w > 0                                     # drops anyone censored before t
fpr, tpr, thr = roc_curve(is_case[keep], risk_scores_train[keep],
                          sample_weight=w[keep])
tau_youden = thr[np.argmax(tpr - fpr)]

# 3. Max log-rank: scan candidate cutpoints, keep the most separating split.
def separation(tau):
    hi = risk_scores_train >= tau
    if hi.all() or (~hi).all():
        return -np.inf
    return logrank_test(T_train[hi], T_train[~hi], ev[hi], ev[~hi]).test_statistic

candidates  = np.quantile(risk_scores_train, np.linspace(0.2, 0.8, 25))
tau_logrank = max(candidates, key=separation)    # see the warning below

# Apply ONE frozen cutoff to TEST.
high_risk_test = risk_scores_test >= tau_median  # or tau_youden / tau_logrank
```

The Youden block is the cumulative/dynamic case/control split of
[3.4 Time-Dependent AUC](3.4_time_dependent_auc.md) made explicit: cases carry weight
$1/\hat G(T_i)$, controls share $1/\hat G(t)$, and subjects censored before $t$
get weight zero because their status at $t$ is unknown. Feeding those weights to
`roc_curve` reproduces `cumulative_dynamic_auc` exactly, so the cutoff you read
off it is the cutoff belonging to the AUC you report.

> **Warning: max log-rank inflates significance.** Scanning many candidate thresholds and keeping the best is multiple testing: the resulting log-rank p-value is **not** a valid significance test. Validate the chosen split on a held-out set or independent cohort, and never report the *training* p-value as a significance result.

Use the same horizon $t$ here as the one you report for the
[time-dependent AUC](3.4_time_dependent_auc.md). Choosing one horizon there and a
different one here leaves the threshold and the discrimination number describing
two different clinical questions.

## Plotting

```python
from lifelines import KaplanMeierFitter
kmf = KaplanMeierFitter()
kmf.fit(T, E, label="All patients")
kmf.plot_survival_function()
```

### Stratified plot (the evaluation use case)

The clinically meaningful figure overlays the model's risk groups on one axis, with at-risk counts underneath (see [5.2 lifelines](../05_packages/5.2_lifelines.md)):

```python
from lifelines import KaplanMeierFitter
from lifelines.plotting import add_at_risk_counts
import matplotlib.pyplot as plt

high = risk_scores >= tau                        # tau from "Choosing a risk threshold" above
ax = plt.subplot()
km_hi = KaplanMeierFitter().fit(T[high],  E[high],  label="High risk")
km_lo = KaplanMeierFitter().fit(T[~high], E[~high], label="Low risk")
km_hi.plot_survival_function(ax=ax)
km_lo.plot_survival_function(ax=ax)
add_at_risk_counts(km_hi, km_lo, ax=ax)
```

## Key takeaways for applied ML scientists

- **Freeze the cutpoint before the test set.** Every stratified KM plot needs a threshold, and the two outcome-guided rules will manufacture separation if you fit and evaluate them on the same data. Pick $\tau$ on development data, state which rule produced it, and never quote a training max-log-rank p-value as a significance result.
- **Separation is not validation.** Two cleanly split curves show the score *orders* patients; they say nothing about whether the predicted probabilities are right. Pair the figure with a continuous-score metric ([C-index](3.1_c_index.md), [time-dependent AUC](3.4_time_dependent_auc.md)), a calibration check, and confidence bands with numbers at risk.
- **The covariate-free KM curve is your floor.** It is the "no model" prediction, so a [Brier score](3.2_brier_score.md) that fails to beat it means the model adds no out-of-sample probability information over that window.

## Limitations

- Univariate, so it does not adjust for covariates. For individualized, covariate-aware $S(t)$ you need a model (see [2.1 Cox Proportional Hazards Loss](../02_loss_functions/2.1_cox_ph_loss.md)–[2.4 DeepHit Loss](../02_loss_functions/2.4_deephit_loss.md))
- Cannot extrapolate beyond the last observed event
